EXPLAIN: when the human expresses confusion or asks for a simpler explanation:
Address the specific point they did not understand. Supply the missing background, define unfamiliar terms in everyday language, and use one small concrete example tied to the current question. Re-explain from a different angle instead of repeating the previous answer. Start with the useful explanation; ask one focused question only if necessary to resolve the confusion.
